# Pages

Route-bound pages, tied to Nuxt's file-based routing under `app/pages/`. Each page can co-locate its own components, composables, services, and store.

## Folder Structure

```
app/pages/{page-name}/
├── PageName.vue                # Root page component
├── page-name.service.ts        # Page-scoped API service (optional)
├── page-name.store.ts          # Page-scoped store (optional — shared state only)
├── composables/                # Page-scoped composables (optional)
└── components/                 # Page-scoped components (auto-imported)
```

Co-located files are auto-imported (see [.config/auto-imports/](../../.config/auto-imports/)). The pages scanner ignores `components/` and `composables/` folders (`.config/pages/`), so they never become routes.

## Routing

- `experimental.typedPages: true` is on — route names are type-checked
- Always use named navigation: `navigateTo({ name: 'trips-tripId-plan', params: { tripId } })`, never a string path
- Route names are auto-generated by Nuxt; see `.nuxt/types/typed-router.d.ts`
- Dynamic params via brackets: `app/pages/trips/[tripId]/plan.vue` → `{ name: 'trips-tripId-plan', params: { tripId } }`; read them with `useRoute('trips-tripId-plan').params`
- The plan page URL is the link sent in the WhatsApp message — it must open the trip on its own, with no prior state in the browser

## Layouts

- Default layout in `app/layouts/Default.vue` (header + `<Modals />` host). A page opts into another via `definePageMeta({ layout: '...' })`
- `<UApp>` in `app/app.vue` wraps everything — required for toasts, tooltips and overlays

## Pages Orchestrate Features

Pages compose features — a page can render components from `app/features/` and coordinate between them. Features themselves never depend on other features. For cross-feature communication, the page (or its composable) wires it up.

## Rules

- Single root element per page component
- Use `useHead({ title })` for the per-page title — `Default.vue` applies the `%s | Trip Planner` template
- Static text stays in template — don't extract labels to JS `const` to shorten lines
- Co-located `components/` must live in a `components/` subfolder (auto-import pattern is `app/pages/**/components/**/*.vue`)
- Page-scoped services must end in `.service.ts`; stores in `.store.ts` — required for auto-import
